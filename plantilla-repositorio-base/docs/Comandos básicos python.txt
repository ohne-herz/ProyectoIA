Presentación en Equipos de Refactorización

1.- Explicación de Refactorizar
La refactorización es el proceso de mejorar la estructura interna del código fuente de un programa sin cambiar su comportamiento externo o funcionalidad visible para el usuario.


2.- Ventajas y el por qué refactorizamos
1- Código limpio	Elimina redundancias, variables innecesarias y exceso de parámetros o condiciones, lo que facilita extender funcionalidades, depurar y entender software ajeno
2- Mejor rendimiento	Sin clases, funciones ni variables sobrantes, la aplicación respondería más rápido y mejoraría la experiencia del usuario
3- Ahorro de tiempo y dinero	El código claro reduce el tiempo para implementar features; el no refactorizado encarece la evolución y la corrección de incidentes
4- Menor deuda técnica	El costo del software no termina en la primera versión; sin mejoras periódicas se acumula deuda técnica
5- Evitar obsolescencia	Librerías y frameworks desactualizados o sin mantenimiento pueden romper la aplicación o generar errores
6-Bugs más fáciles de encontrar	Entender la estructura y cómo se conectan las piezas simplifica las pruebas y la detección de errores
7-Mejor diseño del sistema	Con el tiempo se aprende más del dominio, y una solución que fue buena hace meses puede simplificarse; los atajos baratos de corto plazo generan problemas en el largo plazo
